# Tail-Latency-Aware SWAN for HRLLC under Bursty Traffic

Research package for the manuscript *"Tail-Latency-Aware Segmented Waveguide-Enabled
Pinching-Antenna Systems for Hyper-Reliable Low-Latency Communications Under Bursty Traffic"*
(target venue: IEEE Transactions on Wireless Communications).

## Layout

| Path | Content |
|---|---|
| `paper/main.tex`, `paper/refs.bib` | IEEEtran journal manuscript (Abstract, Introduction, System Model, Problem Formulation, Proposed Scheme, Simulation Results, Conclusions). Mathematical derivations assigned to the co-author are marked `[To do]`. |
| `paper/figures/` | Figures generated by `sim/plots.py` (PDF + PNG). |
| `sim/` | Python simulation framework (see below). |
| `results/` | Raw simulation outputs (one JSON per run) used by the figures. |
| `docs/feasibility_assessment_vi.md` | Feasibility assessment for TWC (Vietnamese). |
| `docs/research_design.md` | Model, problem, algorithms and experiment plan (single source of truth). |
| `docs/math_todo_for_colleague.md` | Hand-off list of every derivation/proof left to the co-author. |

## Simulation framework (`sim/`)

* `swan.py` – SWAN geometry, LoS channel with in-waveguide phase/attenuation, equal-gain aggregation, equal-SNR zero-forcing with per-segment power constraints, per-subset SNR tables.
* `fbl.py` – finite-blocklength normal approximation (rate, error probability, best bundle size).
* `traffic.py` – ON–OFF (Markov-modulated) / Poisson / periodic-with-jitter sources; closed-form tail-latency-aware required rate.
* `placement.py` – TAPP (tail-aware block-coordinate placement) and benchmark placements.
* `scheduler.py` – packet-value tail-aware scheduler (proposed), weighted (max-weight, M-LWDF, PF), EDF and round-robin schedulers.
* `simulator.py` – slot-level simulator with deadline-constrained queues, ARQ, virtual credits, reconfiguration delay, Rician option.
* `experiments.py` – experiment definitions and a resumable multiprocessing runner.
* `plots.py` – figure generation (IEEE style, colour-blind-safe palette with marker/linestyle encoding).

### Requirements
Python ≥ 3.10 with `numpy`, `scipy`, `matplotlib` (`pip install numpy scipy matplotlib`).

### Running
```bash
# quick smoke test (single configuration)
python -c "from sim.simulator import SimConfig, run_config; print(run_config(SimConfig(T=20000))['pv'])"

# all experiments (resumable; ~3 h on 4 cores), then figures
python -m sim.experiments --procs 4
python -m sim.experiments --exp bcd
python -m sim.plots

# a subset, shorter runs
python -m sim.experiments --exp peak burst --T-scale 0.4 --seeds 2
```
